
# Shello Project Overview

Shello is a security-first ecommerce platform for premium phone cases, built with a modern Angular (SSR-ready) frontend and a hardened Node/Express backend.

Key highlights:

* Dark liquid-glass UI with translucent surfaces, a hero-led storefront, and a clean sans type system
* Hero section supports a background image with a dark overlay for contrast
* Strict backend validation for auth, pricing, and stock integrity
* JWT access + rotating refresh token flow with HttpOnly cookies
* Modular architecture for products, orders, and admin operations

This overview will be expanded as features and deployment plans mature.
